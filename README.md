# Sales Data Analysis

## Project Overview
This project analyzes sales data to identify sales trends, top-selling products and business performance.

## Tools Used
* Python
* Pandas
* Matplotlib
* Google Colab

## Key Questions
* Which product has the highest sales?
* Which month has the highest revenue?
* What are the overall sales trends?

## Key Findings
* Canon imageCLASS 2200 Advanced Copier — approximately $61,600 in sales.
* November 2017 — approximately $118,448 in sales.
* Annual sales increased from approximately $484,247 in 2014 to $733,215 in 2017. Sales declined slightly in 2015 before increasing in 2016 and 2017.
